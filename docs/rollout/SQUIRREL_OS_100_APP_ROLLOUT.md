## Deployment Methodology

### Credit-Efficient Approach
1. **Single installer function** on Gabriel — `getSquirrelOSInstaller` returns full template as JSON
2. **One short builder message per app** — standardized instruction to create entities + seed data
3. **Batched 5 at a time** — rate limit is 5 builder messages/min
4. **Zero integration credits** for installation (builder handles entity creation)
5. **Sub-agents** for read-only identification scans (no credit cost)

### What Each App Receives
- 15 Squirrel OS entities (standardized schema)
- 4 OrchestratorAgents (Jasper Supervisor, Amelia Healing Agent, Aegis Monitor, Neural Mesh Coordinator)
- 4 OrchestratorNodes (Alpha, Beta, Gamma, Delta)
- 31 NeuralNodes (5-layer mesh with progressive learning rates)
- 50 AegisPlaybooks (category-adapted: core, security, quantum, compliance, performance, AI/ML)
- Domain-adaptive PQC configuration (builder auto-selects appropriate algorithms)
